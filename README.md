# UGC Notebook

Live site: [UGC Notebook](https://mdo91.github.io/ugc-notebook/)

Open `index.html` in your browser. The notebook is a self-contained web page: no installation, account, server, or internet connection is needed to read it. Watching the linked YouTube videos requires internet access.

The overview connects five chapter mind maps:

1. Find your people
2. Content that clicks
3. Build a creator team
4. The growth loop
5. Your first 30 days

Select a branch to open a chapter. Expand individual ideas, or use **Expand all notes**. Each chapter also includes longer field notes. The navigation adapts to smaller screens, and chapter links support browser Back and Forward.

Content is based on the two video breakdowns supplied for this project. Source timestamps, attribution limits, and original notebook synthesis are identified in **Sources & margins**. Platform tactics and download goals are presented as experiments, not guaranteed outcomes.

All HTML, styles, and JavaScript are in `index.html`. No analytics, tracking, external fonts, external scripts, or storage are used.

## Publishing

GitHub Pages serves the repository root from the `feat/ugc-notebook` branch. Push changes to that branch to update the live notebook. `.nojekyll` keeps this self-contained page on GitHub’s plain static publishing path.
